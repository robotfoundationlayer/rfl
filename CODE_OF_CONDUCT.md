# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, by reference.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Scope

The Code of Conduct applies to all project spaces — this repository (Issues, Pull Requests, Discussions), any official communication channels operated by the Robot Foundation Layer project, and any public spaces when an individual is representing the project.

## Enforcement contact

Reports of unacceptable behavior may be sent to the project maintainer at:

**<yo@vox.delivery>**

All reports will be reviewed and investigated promptly and fairly. The maintainer is obligated to respect the privacy and security of the reporter of any incident.

## Enforcement guidelines

This project follows the **Contributor Covenant Enforcement Guidelines** for determining the consequences of any action deemed in violation of this Code of Conduct:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines>
